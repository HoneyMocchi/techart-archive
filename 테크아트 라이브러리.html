더 깊이: UE5 엔진 스터디

기초 개념이 실제 엔진 안에서 어떻게 구현되는지 UE5.8 소스를 따라가며 정리한 노트입니다.

메시 렌더링 파이프라인
StaticMesh / SkeletalMesh가 실제로 그려지기까지 — 버텍스 팩토리, FMeshBatch, 드로우 커맨드 캐싱을 다룹니다.
렌더링 내부구조 스터디
머티리얼 작성부터 화면 출력까지 — 머티리얼 번역, 셰이더 컴파일, 패스 구성 전체 흐름을 다룹니다.
레거시 쉐이딩 모델 시스템
16개 ID 제한의 원인, ShadingModels.ush 읽는 법, Material IR(5.8 신규)까지 레거시 파이프라인의 뼈대를 다룹니다.
Substrate 시스템 분석
레거시와의 구조 차이, 타일 분류 최적화, 모바일 제약, 레거시를 대체하는 이유를 다룹니다.
