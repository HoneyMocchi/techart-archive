MainDev 학습 아카이브

UE5.8 커스텀 엔진(툰 쉐이딩) 작업을 진행하며 정리한 학습·구현 문서 모음입니다. 왼쪽 목록이나 아래 카드에서 문서를 고르면 됩니다.

문서 목록

엔진 스터디
레거시 쉐이딩 모델 시스템
16개 ID 제한의 원인, ShadingModels.ush 읽는 법, Material IR(5.8 신규)까지 레거시 파이프라인의 뼈대를 다룹니다.
엔진 스터디
Substrate 시스템 분석
레거시와의 구조 차이, 타일 분류 최적화, 모바일 제약, 레거시를 대체하는 이유와 툰 쉐이딩 시사점을 다룹니다.
구현 보고서
ToonLit 쉐이딩 모델 구현
얼굴 2D 오프셋 그림자, Toon Profile 연결, 반투명 눈썹 fade의 구조와 변경 파일 목록을 정리했습니다.
엔진 스터디
메시 렌더링 파이프라인
StaticMesh / SkeletalMesh가 실제로 그려지기까지 — 버텍스 팩토리, FMeshBatch, 드로우 커맨드 캐싱을 다룹니다.
엔진 스터디

머티리얼 작성부터 화면 출력까지 — 머티리얼 번역, 셰이더 컴파일, 패스 구성 전체 흐름을 다룹니다.

추천 읽기 순서

처음이라면 다음 순서로 읽는 것이 흐름이 자연스럽습니다.

  1. 쉐이딩 모델 시스템 — 레거시 시스템의 구조와 한계
  2. ToonLit 구현 — 그 위에 구현한 커스텀 모델
  3. Substrate 분석 — 레거시를 대체하는 차세대 시스템과 앞으로의 방향
  4. 메시 렌더링 파이프라인 · 렌더링 내부구조 — 파이프라인 전체 그림으로 확장

md 파일과의 동기화

이 페이지의 문서 6종은 같은 폴더의 md 파일이 원본입니다. 로컬 HTTP 서버(예: VSCode Live Preview)로 열면 md 수정이 자동으로 반영되고, 파일로 직접 열 때(file://)는 내장 스냅샷이 표시되므로 Sync-StudyLibrary.ps1을 실행해 스냅샷을 갱신하면 됩니다.
