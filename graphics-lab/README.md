# 그래픽스 기초 랩

컴퓨터 그래픽스의 기초를 직접 만지며 익히는 인터랙티브 교재입니다. 78개 주제마다 끌고 돌리고 재생할 수 있는 그림이 2~6개씩 들어 있고, 장 끝마다 실무·실생활 활용(`use` 블록)을 정리했습니다. 휴대폰에서는 점 근처를 잡으면 드래그, 그 밖은 페이지 스크롤로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. 빌드나 서버가 필요 없습니다. `index.html#4`처럼 번호를 붙이면 그 주제부터 열립니다.

사이트(`../테크아트 라이브러리.html`)에는 이 폴더를 묶어서 넣습니다. 원본을 고친 뒤 `../scripts/Bundle-GraphicsLab.ps1`을 실행하세요.

## 파일 구조

- `js/core/format.js`: 본문 서식(`$수식$`, `==형광펜==`, `**굵게**`, `[[색:글자]]`)과 수식 하이라이트, 3b1b 팔레트
- `js/core/fig.js`: 그림 틀 — 캔버스, 월드 좌표, 드래그 핸들, 재생·전환 애니메이션, 그리기 도구, 3D 궤도 카메라, 조작부
- `js/core/meta.js`: 주제별 난이도(기초·중급·심화)와 태그. 라이브러리의 검색·필터가 씁니다
- `js/core/lab.js`: 주제 등록(`lesson({...})`), 화면 구성, 주제 전환
- `js/lessons/NN-이름.js`: 주제별 본문과 그림. 파일 이름 순서가 곧 주제 순서입니다
- `js/app.js`: 시작, 홈 화면용 그림, 라이브러리 연동(`window.GFXLab`)
- `styles/app.css`: 랩 스타일. 그림 상자는 테마와 관계없이 항상 어두운 배경입니다

## 색 약속

모든 주제에서 같은 기호는 같은 색입니다: x·î는 초록, y·ĵ는 빨강, 각도 θ는 파랑, 주인공 벡터 v는 노랑. 행렬은 첫째 열(î가 도착한 곳)이 초록, 둘째 열(ĵ)이 빨강, 이동 열이 청록입니다.

## 주제 하나의 구조

```js
lesson({
  topic: "vector", title: "벡터와 좌표", desc: "숫자 두 개 = 화살표 하나", stage: "공간의 언어",
  sym: { v: "yellow" },                       // 이 주제의 기호 색
  hook: "한 줄 소개",
  blocks: [
    "본문 문단 — $v = (x, y)$, ==중요한 부분==",
    { h: "소제목" },
    { fig: { aspect: 0.5, view: { x0: -5, x1: 5, y0: -2.6, y1: 2.6 }, eq: ["v = ({v.x}, {v.y})"],
             setup(F, C, L) { /* 핸들·조작부·F.draw 정의, L.set("v.x", 값) */ } } },
    { key: "핵심 한 줄" },
    { ponder: "질문", answer: "답" },
    { use: [["엔진", "제목", "실무에서 어떻게 쓰이는지"]] },
    { recap: [["수식", "설명"]] }
  ]
});
```
