# Graphics Foundations Lab

그래픽스의 기초를 배울 때 필요한 수학/컴퓨터 지식을 한 화면에서 실험할 수 있는 독립형 HTML 콘텐츠입니다.

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. 별도 빌드, 패키지 설치, 로컬 서버가 필요하지 않습니다.

## 파일 구조

- `index.html`: 앱 셸과 스크립트/스타일 연결
- `styles/app.css`: 전체 다크 테마와 레이아웃 스타일
- `js/sections/`: 주제별 HTML 섹션 템플릿
- `js/common/state.js`: 전역 상태와 색상 토큰
- `js/common/app-core.js`: 네비게이션, 입력 동기화, 렌더 루프
- `js/common/canvas-utils.js`: 캔버스, 수학, 카드 렌더링 공통 함수
- `js/common/interaction.js`: 드래그 입력과 자동 애니메이션
- `js/topics/`: 주제별 캔버스 드로잉과 계산 로직
- `js/app.js`: 주제 등록과 앱 초기화

## 포함된 주제

- 벡터와 좌표
- 삼각함수와 회전
- 내적과 외적
- 행렬 변환
- 카메라와 투영
- 래스터화와 보간
- UV와 텍스처 샘플링
- 노멀과 조명
- GPU 파이프라인과 메모리

## 상호작용

- 다크 모드 UI
- 캔버스 그래프 직접 드래그 조절
- 주제별 자동 애니메이션 버튼
- 계산 결과 카드
- 수식과 처리 순서를 단계별로 보여주는 패널
- 행렬 변환 주제의 `S`, `R`, `T`, `T * R * S` 행렬 분해 보기

각 주제는 슬라이더, 세그먼트 선택, 캔버스 시각화, 계산 결과 카드, 단계별 수식 흐름으로 구성되어 있습니다.
